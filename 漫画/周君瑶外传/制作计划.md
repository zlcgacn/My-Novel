# 周君瑶外传·漫画制作计划

> 2026-11-01 定。先画第一章，整条流程跑通后再画第二章；第三、四章等正文定稿再开始。

## 定下的形式

- **彩色页漫**，竖版单页，从左往右读，一章一话。内心独白多，用页漫的方框旁白比条漫放得下。
- 画风：WAI-illustrious 模型，**周君瑶第一批设定图那种彩色动漫画风**，CFG 4.5，负面压油光和写实感（2026-11-01 作者定：喜欢原图，只是要去掉 AI 感、配角要画好）。备用画风是钢笔墨线加网点。画风词见 `角色设定.md` 开头。**2026-11-02 作者意见：光影感太重、AI 感重，还要改**，正在试去光影的方向。
- 字：画面一律不带字，对白、旁白、拟声字都由我用脚本排上去。对白用思源黑体（Noto Sans SC），她心里的话用楷体，旁白方框用宋体（Noto Serif SC），这几种字体系统里都已经有了。
- 篇幅估算：第一章约 24 页，第二章约 24 页。

## 出图方式

ComfyUI 开着的时候，我通过它的本地接口（127.0.0.1:8188）提交工作流、取回图片，**不需要装任何插件**。你只需要：开着 ComfyUI，看图，挑图。

## 步骤

### 第 1 步　角色与场景设定　　【我做】

- 每个出场人物写一份外貌定法和提示词：周君瑶、早川千鹤、鹅、圆脸、同桌、级任先生、校长、老护院、管家；第二章加高个子男生（姜振宇）；第三章再加父亲、宫本小夜。
- 场景：礼堂、教室、院子和水缸、廊下那根柱子、回廊、马车、马厩、伙房、大饭厅、她的屋子。
- 外貌细节以正文为准（她穿深绿裙子、戴呢帽；千鹤盘辫子、深蓝裙子洗得发白），正文没写的由我定。
- **下载：无。**
- 产出：`角色设定.md`、`场景设定.md`

### 第 2 步　定长相　　【我出图，你挑】

- 我通过接口给周君瑶、早川千鹤各出一批设定图（三视图加表情），其他人各出几张。
- 你挑定每个人的长相，挑中的图存进 `图/设定/`。
- **下载：无。** 需要你开着 ComfyUI。

### 第 3 步　训练角色 LoRA　　【我做，你开机等着】

- 只训练周君瑶和早川千鹤两人，她们几乎每页都出现。其他人靠提示词加固定种子。
- 我用挑定的长相、**按定下的彩色画风（CFG 4.5、去油光负面）**再出 30 张左右单人图当训练素材，人工剔掉长得不像的，然后训练。素材必须是定下的画风，LoRA 会连画风一起学进去。
- **下载（到这一步再装，全部装在 D 盘）：**
  1. **Python 3.11**（约 25MB）。你电脑上只有 Python 3.14，太新，训练工具的依赖装不上。
  2. **kohya sd-scripts**（GitHub `kohya-ss/sd-scripts`，用 git 下载，很小）。
  3. 训练依赖（PyTorch cu128 等，约 5～6GB，用 pip 装进 `D:\AI\sd-scripts\venv`）。
- 每个 LoRA 在 5070 上训练大约 40～60 分钟。训练好的 LoRA 放进 `models/loras/`。
- **进度（2026-11-02）**：周君瑶 LoRA 训练完成（`zhou_junyao.safetensors`，强度 0.8，30 分钟），用法和同框换脸的做法写在 `角色设定.md` 周君瑶条目里。早川千鹤的还没训练。校服第一版、周君瑶的红头绳标识都被作者否决，待重新设计（校服暂时搁置）；这两样和画风定了以后，周君瑶的 LoRA 要用新画风、新标识的素材重训。2026-11-03 已用 E 画风重训一版（`zhou_junyao_e`），作者要求再迭代至少 5 轮，直到任何角度都不崩。
- **进度（2026-11-04）**：迭代 6 轮，定用 `zhou_junyao_e6.safetensors`（强度 0.8）：脸、五官、身高、比例都稳，头发、裙子颜色对了。静止侧脸露耳朵是底模的习惯，LoRA 和提示词都压不住，出图后用 `脚本/遮耳朵.py` 补，做法写在 `角色设定.md`。每轮结果见 `稳定性测试记录.md`。标识、校服定下来以后还要再重训一次（素材换装）。
- 训练时要关掉 ComfyUI：这台机器的虚拟内存只有 C 盘上的 2GB，两边同时开会因为 Windows 内存额度不够而报“显存不足”。想两边同时开，就在 D 盘加一个 16GB 以上的虚拟内存（系统设置，要你自己改）。

### 第 4 步　分镜脚本　　【我写，你审】

- 第一章逐页逐格写：景别、机位、人物动作和表情、对白、旁白、拟声字、提示词、姿势。
- 原文的心理描写大部分进旁白方框，哪几句留白、哪几句画成画面，我在分镜里标出来。
- 你审分镜，改完再开始出图。
- **下载：无。**
- 产出：`分镜/第一章.md`

### 第 5 步　出图　　【我出，你挑】

- 每格出 4～8 张候选图，你挑一张；挑不中的我改提示词重出。
- 姿势要求严格的格子（伸胳膊进缸里捞笔、拽人起来、推人），由我用脚本画 OpenPose 骨架，交给 ControlNet 控制姿势。
- 小格子里的脸由 FaceDetailer 自动修。
- **下载（到这一步再下）：**
  1. **ControlNet Union SDXL promax**（HuggingFace `xinsir/controlnet-union-sdxl-1.0`，文件 `diffusion_pytorch_model_promax.safetensors`，约 2.5GB），放进 `models/controlnet/`。
  2. HuggingFace 在国内连不上的话，换镜像站 `hf-mirror.com` 下载，文件路径一样。
- 产出：`图/第一章/` 下按页、格编号的成图。

### 第 6 步　排版加字　　【我做】

- 用 Python 脚本按分镜把图裁进分格、画格框，加对白气泡、旁白方框和拟声字。
- 单页尺寸按 B5 漫画原稿比例，导出 300dpi PNG。
- **下载：无。**

### 第 7 步　校对和导出　　【你看，我改】

- 你逐页看，标出要改的地方，我重出或重排。
- 定稿后导出整话 PDF，再导一份手机看的长图。
- **下载：无。**
